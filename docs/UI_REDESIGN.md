# 中文界面与登录流程改造

## 架构与范围

保留 Rust + GPUI 0.2.2，无技术栈迁移。`api/auth/files/download/transfers` 的请求、安全和任务逻辑继续复用；错误文字中文化，凭据读取新增“无会话/数据损坏/访问失败”区分。没有改写整个仓库。

- `src/ui/mod.rs`：原生窗口、文件工具区、虚拟列表/网格、右键菜单、登录验证状态、异步回调。
- `src/ui/pages.rs`：自定义标题栏、导航、中文登录/设置/任务页、后台恢复及主题订阅。
- `src/ui/theme.rs`：统一浅色/深色色板，无计时轮询、无 Entity 引用。
- `src/ui/input.rs`：保留已有输入和 IME 实现，背景、文字/占位符随主题变化。
- `src/settings.rs`：默认跟随系统；旧配置兼容；主题选择自动异步持久化。
- `src/credentials.rs`：缺失条目返回 NoSession；损坏数据返回 InvalidSession；访问失败不再与无账号混淆。退出删除在后台执行，不宣称失败保存成功。
- `resources/mokawa.ico`、`mokawa.rc`：原创几何 M 图标、中文产品信息；安装向导改简体中文。

## 标题栏与主题方案

核对当前发行包源码：Windows `titlebar.appears_transparent=true` 隐藏系统标题栏；`window_control_area(Drag/Min/Max/Close)` 映射原生 HTCAPTION/HTMINBUTTON/HTMAXBUTTON/HTCLOSE，平台层保留缩放和双击。平台已处理控制动作，UI 不再另触发一次最大化。

系统外观通过 `Context::observe_window_appearance` 订阅，订阅由视图持有，窗口释放后移除；没有新增轮询。Windows 上游响应 `ImmersiveColorSet` 并查询 UISettings。手动主题保持不受系统外观覆盖。标题栏、输入框、列表、导航、任务、确认区域共享色板，窗口仍使用不透明背景，不宣称 Mica/Acrylic。

## 登录行为与真实限制

首次启动显示“连接 PikPak 账号”。没有有效会话时不显示已登录文件主页，不显示“退出登录”。授权按钮明确提示尚待客户端注册，另有官方说明入口；未伪造授权 URL、回调或成功响应。

保存会话在后台读取，仅真实 PikPak 文件请求成功后进入文件页；验证可取消，过期/无效/凭据错误返回登录页。取消递增 generation，过时的异步结果不能覆盖新状态。退出取消文件/下载任务、清理本地会话；删除失败明确显示失败并允许重试。尚未实现服务端授权撤销。

2026-10-17 再次只读访问官方 OIDC 发现端点成功；官方 CLI 文档仍说明浏览器 OAuth/设备授权，并明确不支持密码登录。尚未确认 Mokawa 专属客户端注册、原生回调/public client、Token audience 对文件 API 的约定。官方 CLI 自己能登录不等于 Mokawa 可以复用其身份。本轮不提供密码输入框，不复制其他客户端 ID/secret，不索取导出的 Token。

因此“真实授权成功、取消官方授权、回调错误和过期处理”的端到端验收仍受注册与合法测试账号阻塞；本轮只完成真实的未接入状态、会话验证和本地取消交互。

## 文件功能边界

现有列表、面包屑、当前目录搜索、排序、多选、新建、重命名、删除确认、详情和下载仍调用现有真实 HTTP 实现。网格按窗口宽度分组并虚拟滚动；右键操作使用同一业务入口。重命名前需在工具区填写名称。Esc 关闭菜单或撤销待确认删除。

上传、移动、收藏、最近访问、分享、离线任务、完整回收站及媒体仍未接入；导航或按钮明确提示不可用。没有静态网盘数据。未授权前，这些真实 API 行为也不能用 Mock 结果代替账号验收。

## 验证方法

- 核心/Mock、原有生命周期和容量测试保留；新增旧配置迁移与三主题持久化测试。
- Windows 凭据测试使用隔离的合成条目，新增缺失/损坏数据错误区分测试。
- `scripts/windows-smoke.ps1`：实际 Windows 八个页面/主题/尺寸场景及截图。
- `scripts/windows-window-controls.ps1`：真实命中测试和鼠标交互，验证拖动、双击、最小化、最大化/还原和关闭。
- `scripts/windows-theme.ps1`：隔离偏好目录，重启真实窗口，检查保存主题对应的标题栏像素；不包含真实凭据。
- `scripts/windows-performance.ps1`：保留三轮空闲与窗口关闭资源采样，不据短时结果宣称无泄漏。

Windows 10/11 实机、高 DPI、多显示器、系统主题运行中切换、完整 IME、多文件真实渲染、真实认证和 24 小时运行仍需单独验收。
